# 대전성모여자고등학교 신입생 안내

중학생과 학부모가 대전성모여자고등학교의 배움과 학교생활을 살펴볼 수 있는 **2027 신입생 홍보 페이지**입니다.

**[학교 소개 사이트 바로가기](https://seongmo-school-guide.vercel.app/)**

## 주요 내용

- **학교 소개**: 학교 전경, 교훈, 상징과 학생 활동
- **성모의 하루**: 등교, 수업, 점심시간과 일과시간표
- **내가 찾는 진로, 내가 만드는 미래**: 관심 분야와 직업 이름을 바탕으로 살펴보는 과목 선택 예시
- **진로 체험**: 대학 전공·학과 체험, 졸업생 멘토링, 진로진학 주제탐방단
- **동아리 활동**: 23개 동아리의 이름·활동 검색과 분야별 탐색
- **교복과 학교 공간**: 하복·동복 캐릭터, 도서관, 학습실과 휴게 공간
- **졸업생 응원과 방문 안내**: 선배들의 이야기, 자주 묻는 질문, 학교 위치와 문의 방법

## 구성 방식

HTML, CSS, JavaScript로 만든 정적 웹사이트입니다. 별도 빌드나 패키지 설치 없이 실행하며, 데이터베이스와 회원가입 기능은 없습니다. 과목 추천은 미리 작성한 교육과정 자료를 브라우저에서 처리하는 방식입니다.

휴대전화와 컴퓨터 화면에 맞춰 배치가 달라지며, 이미지에는 WebP와 화면 크기별 파일을 사용합니다. 학교와 활동 이미지는 실제 사진을 바탕으로 재구성한 일러스트입니다.

## 내 컴퓨터에서 실행하기

Node.js가 설치된 컴퓨터에서 저장소를 내려받은 뒤, 프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
node server.mjs
```

브라우저에서 **http://localhost:4173** 을 엽니다. 종료하려면 실행한 터미널에서 `Ctrl+C`를 누릅니다.

## 파일 안내

| 파일 또는 폴더 | 역할 |
| --- | --- |
| `dist/index.html` | 페이지 문구와 전체 구조 |
| `dist/styles.css` | 기본 색상과 화면 배치 |
| `dist/polish.css` | 화면 세부 스타일 |
| `dist/magazine.css` | 현재 잡지형 배치와 모바일 스타일 |
| `dist/app.js` | 동아리 검색, 공간 목록, 메뉴와 이미지 확대 등 |
| `dist/curriculum-data.js` | 교육과정과 진로별 과목 자료 |
| `dist/curriculum-ui.js` | 관심 분야 선택과 추천 결과 표시 |
| `dist/motion.js` | 첫 화면 캐릭터 움직임 제어 |
| `dist/assets/` | 교표, 교복 캐릭터, 학교·활동 일러스트 등 |
| `server.mjs` | 내 컴퓨터에서 확인하기 위한 서버 |
| `vercel.json` | Vercel 배포 설정 |

## 내용 수정과 확인

1. 바꿀 내용에 해당하는 파일을 수정합니다.
2. 로컬 서버에서 문구, 사진, 링크를 확인합니다.
3. 휴대전화처럼 좁은 화면에서도 글과 이미지가 잘 보이는지 확인합니다.
4. 과목 추천, 동아리 검색, 교복 전환, 이미지 확대 기능을 확인합니다.

교육과정 자료를 바꿀 때는 과목 이름뿐 아니라 학년·학기와 선택 조건도 함께 확인해야 합니다. 추천 결과는 과목 선택을 돕는 예시이며, 실제 개설 과목과 프로그램은 학교의 최신 안내를 기준으로 합니다.

## 배포

현재 사이트는 Vercel의 `seongmo-school-guide` 프로젝트에서 운영합니다. `vercel.json`은 `dist` 폴더를 배포 대상으로 지정하며, 별도 설치·빌드 명령은 사용하지 않습니다.

GitHub 저장소의 `main` 브랜치가 배포 프로젝트에 연결되어 있습니다. 운영 화면을 수정한 뒤에는 실제 공개 주소에서 반영 여부와 주요 기능을 다시 확인합니다.

## 자료와 개인정보 관리

- 학교가 제공한 안내 자료와 활동 자료를 바탕으로 구성했습니다. 운영 과목, 동아리, 일정과 교통 정보는 학교의 최신 확정 내용을 확인해 갱신합니다.
- 학생 이름·학번·얼굴·연락처가 담긴 원본 자료나 캡처를 새로 저장소에 올리지 않습니다.
- `.env.local`, 인증 파일, `.vercel` 폴더와 비밀번호·토큰·API 키를 저장소에 올리지 않습니다.
- 학교명, 교표, 사진과 일러스트의 이용 권한을 확인한 뒤 재사용합니다. 이 저장소는 해당 자료의 자유로운 재배포 권한을 부여하지 않습니다.
