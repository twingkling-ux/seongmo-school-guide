# 대전성모여자고등학교 소개

`dist/index.html`이 시작 파일입니다. 별도 설치나 데이터베이스 없이 정적 웹 서버에서 실행됩니다.

```powershell
node server.mjs
```

브라우저에서 http://localhost:4173 을 엽니다.

## 수정 위치
- 글과 구조: `dist/index.html`
- 색상과 배치: `dist/styles.css`
- 동아리·공간 목록 및 기능: `dist/app.js`
- 제공 사진·교복 캐릭터: `dist/assets`

자료 기준: 이전 채팅에서 제공한 학교 안내 자료 및 동아리 23개 목록. 지난 연도, 비용, 입학 일정, 담당 교사 이름은 공개 화면에서 제외했습니다. 원본 자료는 수정하지 않았습니다. 공간 사진은 제공된 사진 모음의 해당 영역을 CSS로 표시합니다.

운영 과목과 동아리의 최신 확정 내용은 학교 확인이 필요합니다.
